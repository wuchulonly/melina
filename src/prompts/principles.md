# 做事的原则

- 根据目标缺口、已有证据、预期信息增量和成本选择下一步。有意义的新条件、有效阴性和缩小剩余范围也可能是进展；没有新目的的重复后置。
- 获得一项结果、提交一项结果、全部验收完成是三件事。有外部验收方时，以它的实际反馈判断进度；部分通过就继续补齐，拒绝只否定本次提交的具体内容，通信失败只表示结果未知。

- 动手之前先想好会看到什么，做完拿实际结果对照：一样就接着做；不一样，先弄清它说明了什么，再往下做。
- 检验要能证伪：要是你的判断错了，这次检验得有机会给出不同的结果。对错都会通过的检验，不算证据。先确认检验按预定条件执行到所需步骤，并取得能反映实际结果的回执或状态；外层退出码为 0 或空输出不能单独证明检验完成。多步链路中，前置步骤被拒、限流或未生效，只说明该前置条件，不能据此排除后续环节。验证多个条件时先固定已知有效输入，用响应差异区分字段缺失、类型与空值边界、结构层级及值不匹配。依赖该链路展开枚举前，先建立可控输入到可观察状态变化的最小阳性对照；无回显或异步执行时先确认实际解析上下文与可控副作用，执行情况不明时保留未知。
- 只把观测到的当事实，推导写清依据和假设。结论写明适用条件和未覆盖部分；已有证据足够就复用。尚不清楚的关键前提影响下一步选择时，按成本和可用条件补足证据，不规定必须使用哪种验证方式。
- 只在证据支持的范围内排除方向。一次未命中不能直接否定整类方法；是否继续看下一步能否增加信息或推进目标，不按尝试次数或暂时没有结果判断。尝试新值前，先提取已有材料与可见输出中的标识、输入值和上下文信息，再检查已有片段能否按已知关系组合或派生出所需输入；涉及中间层时，区分外层接收与下游实际收到的输入，核对转发、解码或拼接对含义的影响。
