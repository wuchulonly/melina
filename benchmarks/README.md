# 场景题范围

当前外部题库是一道 `security-audit`：调查本地 Web/API 应用中的越权，交付接口清单与复现证据。题目给出业务鉴权约定、测试账号和可运行的应用；具体问题与触发条件需要通过检查材料、发请求和观察副作用确定。可以阅读源码辅助调查，交付不要求修改源码。

判题核对漏洞接口集合，报告供人工复核；`audit/verify_truth.py` 通过真实请求验证预置真值。这是有源码材料的开发集场景，不是只有一个网址的黑盒靶场，也不是留出集。
