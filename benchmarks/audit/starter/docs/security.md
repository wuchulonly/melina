# 鉴权约定

这份文档是 acme-api 的鉴权基线，所有接口都应当遵守。

## 身份

- 请求带 `Authorization: Bearer <令牌>`。令牌对应一个用户；认不出或者没带，就是匿名。
- 认人在全局的 `before_request` 里做（`app/__init__.py`），它只负责把当前用户放进 `g.user`，
  **不负责拦截**。要不要登录、是不是本人、是不是管理员，由各个接口（装饰器、蓝图钩子或函数体）自己把关。
- 角色：`user`（普通用户）和 `admin`（管理员）。管理员能管理所有人的数据和账号。

## 什么算越权

一个接口如果出现下面任意一种情况，就算越权：

1. **不该匿名的被匿名调用了**：不带令牌（或令牌无效）就能成功调用一个非公开接口。
2. **越过了数据归属**：登录的普通用户能读到、改到或删到不属于自己（或自己团队）的数据。
3. **越过了角色**：普通用户能做只有管理员才能做的事，包括把自己或别人提成管理员。

这里的「成功」看的是**结果**：是不是拿到了不该拿的数据、或者产生了不该有的效果（数据被改了、被删了、
密钥被换了……）。至于最后返回的状态码是 200 还是 403，不作数——哪怕回了 403，只要副作用已经发生，也算越权。

## 公开接口（允许匿名）

只有下面这些接口允许匿名调用，别的一律要登录：

- `GET /api/public/status`
- `GET /api/public/plans`
- `POST /api/auth/login`

## 归属规则

- 文件、发票、便签、报表、Webhook 都有一个 `owner`，只有本人能读写。
- 项目有成员列表（`members`）；项目下的任务属于某个项目，只有项目成员能看和改，而且任务要确实属于那个项目。
- 团队只有成员能看。
- 功能开关谁都能读，但只有内部员工（staff）能改。
